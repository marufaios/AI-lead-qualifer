# Workflows

- [`qualify_lead.md`](qualify_lead.md): enrich and score a lead (the `qualify-lead` task, including the scoring rubric)
- [`deploy_trigger.md`](deploy_trigger.md): deploy the task to Trigger.dev prod

Markdown SOPs, one per job (e.g. `qualify_lead.md`). Each workflow states:

- **Objective**: what the job achieves
- **Inputs**: what's required, and its schema
- **Steps**: the order to run things in and the tool used at each step
- **Outputs**: what's returned, and its schema
- **Edge cases**: failures, missing data, fallbacks
- **Learnings**: quirks and limits found while running it (keep this up to date)
